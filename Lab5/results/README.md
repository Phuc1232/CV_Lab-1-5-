# Kết quả kiểm tra thủ công

## Kết quả được ghi nhận trước đây

Các con số dưới đây là ghi nhận từ tài liệu thực nghiệm cũ, phụ thuộc phần cứng, ánh sáng và ảnh đăng ký.

| Tình huống | Kết quả từng ghi nhận |
|---|---|
| Khuôn mặt chính diện, đủ ánh sáng | Độ tương đồng lớn hơn 0.95 |
| Vector ngẫu nhiên hoặc khuôn mặt ngoài cơ sở dữ liệu | Độ tương đồng từ −0.1 đến 0.4, ứng dụng hiển thị `Unknown` |
| CPU Intel Core, `--frame-skip 2` | Khoảng 15–25 FPS |
| GPU NVIDIA CUDA | Khoảng 35–60 FPS |

## Mẫu ghi kết quả

Ghi kết quả khi chạy nhận diện qua webcam. Bảng này có thể sao chép vào báo cáo mỗi lần đo.

| Mục | Giá trị quan sát |
|---|---|
| Ngày và máy thử | |
| Camera, backend và độ phân giải thực tế | |
| Thiết bị chạy mô hình | |
| Ngưỡng và khoảng cách khung hình suy luận | |
| Nhãn và điểm với khuôn mặt đã đăng ký | |
| Nhãn và điểm với khuôn mặt ngoài thư mục ảnh mẫu | |
| FPS hiển thị và điều kiện ánh sáng | |
